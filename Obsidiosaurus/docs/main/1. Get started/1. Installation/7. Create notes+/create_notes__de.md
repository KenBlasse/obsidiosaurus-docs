

## Mehrsprachigkeit

Wenn du Notizen direkt mehrsprachig aus deinem Vault schreiben möchtest, musst du in deinem Obsidian-Vault folgender Struktur folgen:

```
sidebar
├── 1. First topic
│   ├── 1. First note+ // das '+' zeigt: enthält mehrere Sprachen
│   │   ├── first_note__en.md
│   │   └── first_note__de.md
│   └── 1. Second note+ // das '+' zeigt: enthält mehrere Sprachen
│       ├── second_note__en.md
│       └── second_note__de.md
└── 2. Second topic
    └── ...
```
