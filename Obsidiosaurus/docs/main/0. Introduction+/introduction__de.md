# Einführung

👋 Hallo und willkommen bei **Obsidiosaurus**!

Das Tool, das die Stärken von [Obsidian.md](https://obsidian.md/) und [Docusaurus](https://docusaurus.io/docs) vereint.

Obsidiosaurus dient als **Brücke**, die deinen Obsidian Vault mit dem Page-Builder Docusaurus verbindet.

Es übersetzt die spezielle Markdown-Syntax von Obsidian und konvertiert deine Dateien so, dass Docusaurus sie direkt verarbeiten kann.

> [!note] Stabiles Release
> Obsidiosaurus v1.0.0 ist das erste stabile Release des community-gepflegten Forks.
> Es enthält Docusaurus-v3-Support, keine nativen Abhängigkeiten und mehrere Bugfixes.
>
> Sichere immer deine wichtigen Notizen, bevor du eine Konvertierung ausführst.
