# Anwendung von Obsidiosaurus

Nachdem du Repo, Docusaurus und Obsidian-Vault erfolgreich eingerichtet hast, ist es Zeit zu prüfen, ob Obsidiosaurus erfolgreich läuft.

Sobald du Änderungen an einigen deiner Notizen vorgenommen hast, klicke in deiner linken Sidebar in Obsidian auf `page with up arrow`:

![obsidiosaurus_sidebar_icon](/assets/obsidiosaurus_sidebar_icon.webp)

Das löst den Konvertierungsprozess von Obsidiosaurus aus. Sobald die Konvertierung abgeschlossen ist, erhältst du oben rechts eine Benachrichtigung.

![obsidiosaurus_run_sucess_notifaction_2](/assets/obsidiosaurus_run_sucess_notifaction_2_400.webp)
## Fehler

:::danger[Log-Dateien]

Wenn du auf Fehler stößt, aktiviere den Debug-Modus in den Plugin-Einstellungen und prüfe die Logs in der Obsidian-Konsole.
:::

Um die Konsole zu öffnen, drücke:
- MacOS:
	- `Command`+`Option`+`I`
- Windows:
	- `Control`+`Shift`+`I`

Wähle anschließend oben `Console` aus:
![obsidian_console](/assets/obsidian_console.webp)

Poste deine Logs gerne in den [GitHub Issues](https://github.com/KenBlasse/obsidiosaurus/issues), um Hilfe zu bekommen.
