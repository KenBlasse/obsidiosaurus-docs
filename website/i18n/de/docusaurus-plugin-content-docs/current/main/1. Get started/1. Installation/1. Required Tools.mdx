# Voraussetzungen

## Schritt 1: Benötigte Tools installieren 🛠️

Zuerst musst du sicherstellen, dass die nötigen Tools installiert sind. Prüfe die erfolgreiche Installation, indem du die Versionen abfragst (Befehle im Terminal eingeben).

- [ ] [Node.js](https://nodejs.org/en/download)
	- Prüfen mit: `node --version`
- [ ] [Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
	-  Prüfen mit: `git --version`
- [ ] [Obsidian.md](https://obsidian.md/)
- [ ] [VSCode](https://code.visualstudio.com/) oder eine andere IDE
	- Zum komfortableren Verwalten deiner Docusaurus-Instanz

:::note

ImageMagick wird **nicht mehr benötigt** — Obsidiosaurus v1.0.0 nutzt stattdessen die browser-native Canvas-API für die Bildverarbeitung.
